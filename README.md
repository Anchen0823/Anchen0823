## AI4Math 研究

研究项目统一整理在 **[Anchen-AI4Math](https://github.com/Anchen-AI4Math)**。

**[浏览全部课题与进展 →](https://github.com/Anchen-AI4Math/research-index)**

- **[3SUM](https://github.com/Anchen-AI4Math/3sum)**：算法复杂度分析、解析证书与 Lean 形式化；整理基于既有工作的扩展、阶段材料和验证记录。
- **[Average Sensitivity](https://github.com/Anchen-AI4Math/average-sensitivity-lean)**：多项式阈值函数平均敏感度的 Lean / Mathlib 证明与复验材料。
- **[Prove2Me Workspace](https://github.com/Anchen-AI4Math/prove2me_workspace)**：多课题探索与共享 Lean 工作区，按课题记录状态、依赖和证明进展。

研究结论、验证范围与来源归属见各项目文档；探索中的课题与已验证的结果分开记录。
